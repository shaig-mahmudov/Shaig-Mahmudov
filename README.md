## About Me

Backend-focused software engineer interested in distributed systems, developer tooling, reliability engineering, and application security.

I enjoy designing systems with clear boundaries, predictable failure handling, strong automated testing, and secure delivery pipelines.

My work focuses on understanding how systems behave under concurrency, load, dependency failures, duplicate requests, and other production-like conditions.
